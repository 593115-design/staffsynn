Entity Relationship (ER) Diagram

Database Schema mapping relations across MERN stack collections.

Users Collection
_id: ObjectId [PK]
name: String
email: String (Unique)
password: String (Hashed)
role: 'HR'|'Manager'|'Employee'
department: String
status: String
Leaves Collection
_id: ObjectId [PK]
applicantId: ObjectId [FK -> User]
type: 'Sick'|'Casual'|'Paid'
startDate: Date
endDate: Date
reason: String
status: 'Pending'|'Approved'|'Rejected'
Attendance Collection
_id: ObjectId [PK]
userId: ObjectId [FK -> User]
date: Date
checkIn: String
checkOut: String
status: 'Present'|'Late'|'Half Day'
Announcements
_id: ObjectId [PK]
authorId: ObjectId [FK -> User]
title: String
content: String
category: String
date: Date
Relational Architecture Flow: User records link directly to Leave requests and Attendance logs through foreign key relational bindings. Role-based Middleware validates authentication headers (JWT token containing `user._id` and `user.role`) prior to performing MongoDB queries.

StaffSync System Architecture

MERN Stack (MongoDB, Express.js, React.js, Node.js) MVC Pattern

Frontend (React.js)

  • Role-based dynamic UI component rendering
  • State persistence via Context API / Hooks
  • Tailwind CSS responsive design engine
  • RESTful Client Axios integration

Backend (Express / Node.js)

  • Express MVC Controllers & Router endpoints
  • JWT Token & Bcrypt Auth Middleware
  • Input validation & sanitization
  • Error handling logic wrapper

Database (MongoDB)

  • Mongoose Schemas for data validation
  • Indexed collections for high performance
  • Relational references using `.populate()`
  • Secure database connections
